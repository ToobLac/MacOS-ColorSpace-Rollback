# MacOS Colorspace Rollback

This mod sets the colorspace of Minecraft in 26.2+ on macOS back to Display P3, making the colors more saturated.

See [MC-307336](https://bugs.mojang.com/browse/MC/issues/MC-307336) and [MC-308283](https://bugs.mojang.com/browse/MC/issues/MC-308283) for more information.
